VigiEPP — 100%% portable (sin admin, sin instalar nada)
=========================================================

PARA PCs CON RESTRICCIONES DE SISTEMAS
--------------------------------------
Use SOLO el archivo:  vigiepp-portable-full.zip

1. Copie el ZIP a USB, Escritorio o Documentos (carpeta donde tenga permiso de escritura)
2. Descomprima
3. Doble clic en VigiEPP.bat
4. Se abre el navegador solo

Para cerrar: DETENER.bat

NO necesita:
  - Permisos de administrador
  - Instalar Python
  - Instalar programas
  - Conexion a internet (el ZIP ya trae todo)

Todo queda dentro de esta carpeta (datos en backend\data y forense\data).

Descargar vigiepp-portable-full.zip:
  GitHub -^> pestaña Actions -^> "Build portable Windows" -^> Artifacts
